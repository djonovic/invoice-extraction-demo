What this page shows

  1. Sample invoices inFive one-page PDFs in USD, EUR, GBP, JPY and AUD. Layouts and date formats differ on purpose.
  2. Extract fieldsA Python script reads the text layer with pdfplumber and regex. No LLM, no OCR, no API spend.
  3. Structured rows outOne Invoices row per document, a Line items sheet, and downloadable CSV / Excel files.
  4. Review checksNet + VAT = total, date parsed to ISO, line items sum to net, no duplicate invoice numbers. All five passed.
Download Excel workbook Invoices CSV Line items CSV Review CSV

The workbook has three sheets: Invoices, Line items and Review. The CSVs are the same data, ready to open in Excel or import into Google Sheets. This run uses only the sample documents below.
